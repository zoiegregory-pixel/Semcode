Use Case 5: Capital Cities
Goal in Context  
As a demographer I want to generate reports of capital cities by population so that I can analyse political centres.

Scope  
Population reporting system.

Level  
Primary task.

Preconditions  
Database contains capital city data.

Success End Condition  
Report of capital cities ordered by population.

Failed End Condition  
No report produced.

Primary Actor  
Demographer.

Trigger  
Demographer requests capital city report.

Main Success Scenario

Demographer selects “Capital Cities” report.

System connects to database.

System executes query for capital cities.

Report is displayed.

Extensions

No capital city data → “No records available.”

Schedule  
Release 1.0.
